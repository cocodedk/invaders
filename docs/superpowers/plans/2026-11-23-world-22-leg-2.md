# World 22, Leg 2 (the Pencil Wood) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Leg 2 of world 22: the line ability (the ship's path hangs in the air and stops enemy fire), the Smudge (a Hush that hangs and fires curtains), thorn hedges, and the leg's data, first with a plain view so the owner can fly it.

**Architecture:** Everything new in the core is world-22-only course state and data: `course.line` (stroke segments) beside the existing `course` fields, a `hang` air path and a `curtain` pattern, and a `thorn` ground kind that is a box like the pillar. Leg 1 (`w22-1`) is pinned by a test before any core change and must not move.

**Tech Stack:** Plain ES modules, `node:test`, canvas 2D. No dependencies, no build step.

**Spec:** `docs/superpowers/specs/2026-11-23-world-22-leg-2-design.md` (its parent: `docs/superpowers/specs/2026-11-22-world-22-journey-design.md`).

## Global Constraints

- `src/core` and `src/fx` never touch `window`, `document`, canvas, `Math.random` or `Date.now`; randomness from the passed `rng`, time from `dt`; arrays only for runtime data (replays stay exact). `RUN_V` stays 11.
- Worlds 1-21 stay pinned (`test/core/worlds-unchanged.test.js`); `w22-1` is pinned by Task 0 and must not move: nothing new is hashed or drawn on rng unless the leg uses it.
- Every code file < 200 lines. Tuning values are named, exported constants, defined once; tests read them, never repeat the number or what it works out to.
- Pi 4 at 60 fps: no per-frame `shadowBlur`, cached sprites, at most 600 particles, at most 400 enemy bullets (`MAX_BULLETS`).
- A new core event is in `SILENT` or has a handler (`test/fx/react-all.test.js`).
- Story words are the owner's, word for word: opening card **"THE WOOD REMEMBERS."**, ability caption **"YOUR LINE."**
- Never ease, slow or cap the pointer. No new input fields (no replay format change).
- Browser checks: serve no-store on your own port (not 8022, the owner's); never `pkill` by pattern.
- Conventional Commits; never `--no-verify` (the pre-commit hook runs the whole suite).

## Review Focus

1. A pointer flick across the whole screen once the line is held: only the newest `LINE_SEGS` segments stay, ending nearest the ship (Task 1 test).
2. A respawn while a line hangs: the line is gone and the first jump after the respawn draws nothing (Task 1 test).
3. Slow-mo (a slow power): bullets sweep against the line over `slow`, the line ages over `dt` (Task 1 test).
4. The laser power's beam and the seeds against a thorn box: they hurt it as they hurt a pillar (Task 3 test).
5. A shoot-through hedge arriving with an air craft on screen that soaks up the shots: the leg's data never does that (Task 4 test).
