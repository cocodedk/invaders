# Invaders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use
> checkbox (`- [ ]`) syntax for tracking. TDD: write each listed test first, see it fail, implement,
> see it pass, commit.

**Goal:** A single-player 2D Space Invaders game with 8 film-inspired worlds × 5 levels, free flight,
formations, bosses, power-ups and auto-cut trailers of the player's own runs, installed on the Pi.

**Architecture:** Pure simulation in `src/core` and pure effect state in `src/fx` (tested with
`node --test`); canvas drawing, screens, input, audio and storage in `src/ui`; wired by
`src/main.js`. Core and UI meet only through the `world` object and its `events` queue. The core is
deterministic (seeded rng, fixed 1/60 s tick), which is what makes replays and trailers possible.

**Tech Stack:** Plain HTML/CSS/JS ES modules, Canvas 2D, WebAudio, `node:test`. No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-17-invaders-design.md` — read it fully first; its
"Rules", "Worlds" and "Core contract" sections are binding for every task.

**Reference implementation:** Barrage at `/home/cocodedk/0-projects/artillery` — same architecture.
Where a task says "copy from Barrage", copy the file and adapt it; do not import across repos.

## Global Constraints

- No npm dependencies, no bundler, no build step, no network at runtime; all URLs relative (the game
  is served from a sub-path, `/invaders/`).
- Every code file < 200 lines (JS, HTML, CSS). Split by responsibility when approaching it.
- `src/core` and `src/fx` never touch `window`, `document`, canvas, `Math.random` or `Date.now`;
  randomness comes from an `rng` passed in, time from `dt`. Core iteration order must not depend on
  object-key order of data that changes at runtime (arrays only), so replays stay exact.
- World is 1920×1080, y down. Logic steps at fixed `TICK = 1/60` s. Player zone y ∈ [620, 1040],
  x ∈ [40, 1880]; ship max speed 720 px/s.
- Inputs are quantized before they reach the core: `dx, dy ∈ {-1, 0, 1}`, `target` integer px or
  null, `fire`/`bomb` booleans.
- `localStorage` wrapped in try/catch; the game works without it. Keys prefixed `invaders.`.
- Runs at 60 fps on a Pi 4 (Chromium 153 kiosk): no per-frame `shadowBlur`; glow via cached sprites +
  `'lighter'`; ≤ 600 particles; ≤ 400 enemy bullets.
- Names are original: no film titles, character names, logos or quoted film lines anywhere.
- English only. Commits: Conventional Commits, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A level that cannot be finished — an alien stuck off-screen, a diver that never returns, a boss
   phase with no damageable part — must not exist: Task 6 runs the autopilot with an invulnerable
   ship on all 40 levels and requires `state === 'cleared'` within 180 simulated seconds.
2. A replay must reproduce the run exactly even with mouse targets, Code Rain teleports, Twin Suns
   gusts and Event Horizon gravity: Task 6 records random inputs (keys and mouse) on one level of
   every world and checks the replayed state hash and score match.
3. A hidden tab or a slow frame must not trigger a catch-up storm or desync the recording: Task 11
   tests `advance(acc, dt)` caps at 5 ticks per frame and that only simulated ticks are recorded.
4. The last alien dying on the same tick the ship loses its last life counts as **cleared** (the
   player is favoured): Task 3 test.
5. Corrupted, truncated or old-version saved runs, and blocked `localStorage`, must leave the game
   working and Cinema listing only valid runs: Task 6 (`decodeRun` returns null) and Task 11.

- `difficulty(world, index) -> d ∈ [0,1]` = `((world-1)*5 + index-1) / 39`;

### Task 2: Formations and bullet patterns

**Files:** `src/core/formations.js`, `src/core/patterns.js` (+ `patterns-2.js` if needed), tests.

**Interfaces — Produces:**
- `makeSlots(wave) -> [{ row, col, role, sx, sy }]` — home positions in the top area
  (x ∈ [160, 1760], y ∈ [120, 520]), centred.
- `slotPosition(formation, slot, t, ctx) -> { x, y }` — `t` seconds since the wave started, `ctx =
  { aliveFrac, dir, speed }`. `grid`: steps sideways, drops 24 px at the edges, speeds up as
  `aliveFrac` falls, never below y 560. `sway`/`orbit`/`spiral`/`split`/`rain`/`escort` as in the
  spec. Entry: `entryPosition(formation, slot, u)` for u ∈ [0,1] over 1.5 s from off-screen.
- `diveCurve(from, target, u) -> { x, y }` — a swoop toward the ship's x and back up, u ∈ [0,1] over
  2.2 s; it returns to the slot.
- `emitPattern(pattern, from, target, p, rng) -> bullet[]` with `p = { speed, count?, spread? }`.
  Bullet: `{ pattern, x, y, vx, vy, r, life, warn? , turn? }`. `laser` returns one bullet with
  `warn: 0.8` (a warning line, harmless) that then becomes a beam for 0.6 s. `homing` turns ≤ 60°/s,
  life 4 s. `shuriken`: 0.6× speed, r 18.
- `stepBullet(b, dt, world)` — integrates, homing turn, laser warn→beam, `life` countdown.

**Tests:** for every formation, all slots stay within x ∈ [0, 1920], y ∈ [0, 600] over 60 s;
entry starts off-screen and ends at the slot position; `grid` drops at the edge and its speed rises
as `aliveFrac` falls; dive returns to the slot at u=1; `aimed` bullet points at the target; `fan`
count/spread exact; `ring` is evenly spaced; homing turn-rate respects 60°/s; laser is harmless
during warn; patterns are deterministic per rng seed.

- [ ] Tests → fail → implement → pass → commit `feat(core): formations and bullet patterns`.

### Task 3: World — ship, aliens, waves, collisions, scoring

**Files:** `src/core/ship.js`, `src/core/aliens.js`, `src/core/collide.js`, `src/core/scoring.js`,
`src/core/world.js` (+ `world-step.js` to stay < 200), tests.

**Interfaces — Consumes:** Tasks 1–2. **Produces** (spec "Core contract" exactly):
- `createWorld(level, seed) -> world` (`world.rng = createRng(seed)`); `stepWorld(world, dt, input)` with
  `input = { dx, dy, fire, bomb, target }`.
- Ship: hit radius 14; eases toward input velocity (or toward `target` at max speed);
  base shot: 1400 px/s up, 1 damage, cooldown 0.18 s; `invuln` 1.5 s after a hit; `lives` 3.
- Aliens: spawned per wave with `mode:'enter'` → `'hold'`; divers start dives at random (rng) every
  2–4 s, one at a time per wave at d=0, up to 3 at d=1; firing rate = `ROLES[role].fire * fireMult`.
  Next wave starts when the current one is empty (1.2 s gap, `waveClear` event).
- Collisions: shots vs aliens (circle), bullets vs ship (circle r 14 + bullet r); a bullet passing
  within 28 px without hitting emits `nearMiss` once per bullet.
- Scoring: role scores × combo multiplier; combo +1 per kill within 1.5 s (max ×8), reset after
  1.5 s; clear bonus 2000 + 3000 if `hits === 0`. `stars(world) -> 0..3` per spec.
- `state`: `'intro'` (1.5 s) → `'play'` → `'cleared' | 'failed'`. Every event carries `tick`.

**Tests:** ship clamps to the player zone; easing reaches max speed in < 0.25 s; cooldown respected;
a shot kills a 1-hp grunt, armored needs 3 hits; scoring and combo (×8 cap, reset after 1.5 s);
hit → lives −1, invuln 1.5 s, no second hit while invulnerable; 0 lives → `failed`; last alien
killed → next wave after 1.2 s; last wave cleared → `cleared` with bonus; **last alien dies on the
same tick the ship loses its last life → `cleared`**; stars rule (0 hits ★★★, 1 life lost ★★,
2 lost ★); `nearMiss` once per bullet; `stepWorld` deterministic for a seed and input list.

- [ ] Tests → fail → implement → pass → commit `feat(core): ship, aliens, waves and scoring`.

### Task 4: Power-ups, bombs, bunkers

**Files:** `src/core/powerups.js`, `src/core/bunkers.js`, wiring in `world-step.js`, tests.

**Interfaces — Produces:**
- Carriers drop a pickup on death: 80 % a random power, 20 % a bomb. Pickup falls 160 px/s,
  radius 22, collected by touching the ship; leaves the screen → removed.
- Powers last 10 s; a new one replaces the current. `spread`: 5 shots fanned ±20°; `rapid`:
  cooldown 0.07 s; `laser`: continuous beam above the ship, 26 px wide, 8 damage/s to every alien and
  boss part in the column, carves bunkers; `shield`: every hit absorbed while active.
- Bombs: start 1, max 3, `bomb` input edge-triggered; removes all enemy bullets, 3 damage to every
  alien, 8 % of max hp to a boss; event `bomb`.
- `createBunker(x, y, w, h)` with a `Uint8Array` mask in a stepped arch shape;
  `hitBunker(bunker, x, y, r) -> boolean` (carves on hit, both sides' projectiles stop). Levels with
  `bunkers: true` place 4 bunkers at y 560.

**Tests:** carrier death yields a pickup; drop split ≈ 80/20 over 1000 seeded deaths; pickup
collected only on overlap; power timer 10 s, replacement resets; spread fires 5; rapid cooldown;
laser damages all in its column and only there; shield absorbs; bomb clears bullets, damages,
caps at 3, needs a fresh press; bunker carve removes pixels and a carved hole lets a shot through.

- [ ] Tests → fail → implement → pass → commit `feat(core): power-ups, bombs and bunkers`.

### Task 5: Bosses and world twists

**Files:** `src/core/bosses-data.js` (8 definitions; split into two files if needed),
`src/core/boss.js`, `src/core/twists.js` (+ `twists-2.js`), tests.

**Interfaces — Produces:**
- Boss def: `{ kind, maxHp, size:{w,h}, parts:[{ id, dx, dy, w, h, hp, weak, armor }],
  phases:[{ until /* hp fraction */, move:'sway'|'hover'|'charge'|'orbit', attacks:[{ pattern,
  every, from /* part id */, p }], minions? }] }`. Only `weak` parts take full damage, `armor`
  parts 25 %; boss hp = sum of part hp. Every attack has a telegraph ≥ 0.6 s (event
  `bossWarn`) before it fires. Each boss has 2–3 phases and ≥ 1 weak part exposed in every phase.
  The Twin Suns fortress opens a trench in its last phase that exposes its core.
- `spawnBoss(world, kind)`, `stepBoss(world, dt)` (randomness from `world.rng`); events `bossPhase` (once per crossed
  threshold, in order), `bossDeath` (exactly once) → destruction chain then `cleared`.
- Twists, applied by `applyTwist(world, dt)` (randomness from `world.rng`) on the level's world:
  `bunkers` — bunkers every wave + a carrier "saucer" crossing the top every 20 s;
  `darkness` — `lightning` event every 6–10 s (render-only otherwise);
  `gusts` — `world.wind` re-rolled every 4–7 s within ±120 px/s², added to every bullet's and
  shot's vx;
  `shuriken` — ship shots destroy shuriken bullets they touch;
  `acid` — an armored death drops 3 slow acid bullets over 2 s;
  `glitch` — a holding alien blinks to a free slot every 3–5 s (`teleport` event); a `nearMiss`
  starts bullet time: enemy bullets and aliens step at 0.5× for 2 s, 8 s cooldown;
  `reassemble` — an armored death leaves a wreck (`hp 1`, 2 s); unshot, it respawns as an armored
  alien with 2 hp, once;
  `gravity` — a well at (960, 300) pulls every bullet and shot with `a = 9e6 / max(d², 120²)`;
  anything within 40 px of it is absorbed.

**Tests:** weak part takes full damage, armor 25 %; damage crossing two thresholds in one tick
emits two `bossPhase` events in order and lands in the later phase; `bossDeath` exactly once even
with laser + bomb on the same tick; every attack is preceded by `bossWarn` ≥ 0.6 s earlier; every
phase of every boss has a weak part; each twist's rule (one test each, including gravity bending a
straight shot sideways and gusts moving both sides' bullets).

- [ ] Tests → fail → implement → pass → commit `feat(core): eight bosses and world twists`.

### Task 6: Autopilot, replay, highlights

**Files:** `src/core/autopilot.js`, `src/core/replay.js`, `src/core/highlights.js`, tests (the
all-levels test split one file per world, so `node --test` runs them in parallel).

**Interfaces — Produces:**
- `autopilot(world) -> input` — deterministic, never draws from `world.rng` (a replay does not run
  it, so drawing would desync the sim). Move toward x under the nearest alien/weak part, dodge bullets
  within a cone above the ship, fire constantly, bomb when ≥ 6 bullets are within 160 px or at 1
  life with a boss. Same input shape as a human.
- `encodeInputs(inputs[]) -> string` / `decodeInputs(string) -> inputs[]` (run-length encoded).
- `makeRun(level, seed, inputs, result) -> { v:1, level, seed, ticks, inputs:<encoded>, score,
  stars }`; `decodeRun(obj) -> run | null` (null on wrong `v`, bad shape, bad encoding).
- `replay(level, seed, inputs, { snapshotsAt:[tick] }) -> { world, events, snapshots: Map<tick, world> }`
  (snapshots via `structuredClone`).
- `stateHash(world) -> string` (score, tick, ship x/y/lives, alien count + positions rounded).
- `pickHighlights(events, totalTicks) -> [{ start, end, peak, kind }]` — weights: `bossDeath` 10,
  last alien of the level 6, multi-kill (≥ 3 kills in 30 ticks) 5, `bomb` 4, `nearMiss` 3, combo
  peak 2 × mult; windows 180–300 ticks around the peak, at most 4, non-overlapping, sorted by start.

**Tests:** **every level** cleared by the autopilot within 180 simulated seconds with the ship made
invulnerable (`ship.invuln = Infinity`) — one test file per world; autopilot with normal lives
survives 60 s on `w1-1`; **one level per world**: random inputs including mouse targets, run → replay
gives equal `stateHash` and score; encode/decode round-trips random input lists; `decodeRun`
rejects garbage strings, truncated encodings and `v:0`; a world with a boss survives
`structuredClone` and keeps stepping identically; `stepWorld` on the busiest level (most bullets)
stays under 2 ms per tick at the 95th percentile; highlights non-overlapping, ≤ 4, sorted,
and a `bossDeath` always wins a slot; a run with no events yields an empty list.

- [ ] Tests → fail → implement → pass → commit `feat(core): autopilot, replays and highlights`.
