# World 22, Leg 3 (the Mirror Flats) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Leg 3 of world 22: the lasso (close the line into a loop and everything inside is caught), the Flock, mirror shards, and the leg's data, with the glitter, the loop's flash and the sounds, so the owner can fly it plain.

**Architecture:** The lasso is the line closing on itself: `src/core/course-lasso.js` checks each new line segment against the older ones, catches what the closed part holds and spends that ink. The Flock is twelve ordinary air craft on a new `flock` path; a shard is a new round ground kind that throws a shot back when hit. Every new rule is gated on the `'lasso'` ability or the new kinds, so Legs 1 and 2 do not move (both pinned).

**Tech Stack:** Plain ES modules, `node:test`, canvas 2D. No dependencies, no build step.

**Spec:** `docs/superpowers/specs/2026-11-28-world-22-leg-3-design.md` (parents: the journey design and the Leg 2 design it names).

## Global Constraints

- `src/core` and `src/fx` never touch `window`, `document`, canvas, `Math.random` or `Date.now`; randomness from the passed `rng`, time from `dt`; arrays only for runtime data. `RUN_V` stays 11.
- `w22-1` (`test/core/leg-1-unchanged.test.js`) and `w22-2` (Task 0) must not move; worlds 1-21 stay pinned.
- Every code file < 200 lines (`src/ui/audio.js` is at 198). Tuning values are named, exported constants, defined once; tests read them.
- Pi 4 at 60 fps: no per-frame `shadowBlur`, cached sprites, at most 600 particles, at most 400 enemy bullets (`MAX_BULLETS`).
- A new core event is in `SILENT` or has a handler (`test/fx/react-all.test.js`).
- Story words, approved by the owner 2026-11-28, word for word: opening card **"THE SKY LIES DOWN."**, ability caption **"YOUR CIRCLE."**
- Never ease, slow or cap the pointer. No new input fields.
- Browser checks: serve no-store on your own port (8100+, never 8022, the owner's); stop only your own process, by PID.
- Conventional Commits ending with a Co-Authored-By line naming the model that wrote the commit; never bypass hooks (the pre-commit hook runs the whole suite); `git add` by path.

## Review Focus

1. A pointer jump that draws a whole figure-eight in one tick: exactly one loop closes (the first crossing in segment order), and the recharge stops the second (Task 1 test).
2. A loop drawn while the lasso recharges: nothing is caught, the ink is not spent, the line still stops shots (Task 1 test).
3. A loop round a crate: the crate breaks, and the power-up it drops is collected on the next tick (Task 1 test).
4. A shard hit by a spread volley with the bullet list nearly full, and a shard hit from point-blank range: never more than `MAX_BULLETS`, no return inside `SHARD_MIN_RANGE` (Task 2 test).
5. A Flock that leaves the screen with motes alive, and one caught whole by a loop: no drop, and exactly one drop (Task 3 test).
